# 你好，我是 MA Bin（nannanpa）

深耕高校公文与规划场景，把实战沉淀做成零依赖、规则可读可改的 agent skills。

在「发展规划与学科建设」条线上摸爬滚打，做项目申报、"十五五"规划、上会材料、制度修订这些事。把反复用过、确实好使的做法沉淀成一个个 Agent Skill——不是一次性生成的玩具，是真实办公场景里打磨出来的工具。

## 主力项目：[agent-skills](https://github.com/nannanpa/agent-skills)

面向高校规划与公文写作的实战技能库，遵循开放的 [Agent Skills 规范](https://agentskills.io)，可在 Claude Code、WorkBuddy 等兼容 agent 中直接使用。

- **公文与规划**：`grill-me-gongwen`（动笔前方案拷问）、`docs-cross-check`（交稿前横切一致性复核）、`minfadian`（民法典速查）
- **文档处理**：`docx-track-changes-wps`（WPS 安全的真修订模式）、`pdf-to-md`（中文公文 OCR 清洗）、`read-oversized-image`（超大图片读取）
- **知识与方法**：`rule-miner`（知识资产挖掘）、`skill-origin`（技能溯源核验）、`hongloumeng`（红楼梦双版本语料）
- **工程与自动化**：`agent-bridge`（零常驻 agent 通讯桥）、`memory-cleanup`（macOS 内存卫生）

技能库在 [SkillHub](https://skillhub.cn) 上以「问骥」发布，两边内容同步。

## 信念

- **零依赖优先**：能标准库解决就不引第三方，拷过来就能跑。
- **规则可读可改**：把判据和方法论写进 SKILL.md，而不是封装成黑箱——你要能看懂、能改、能拿去适配自己的场景。
- **实战沉淀**：只收录反复用过、经得起拷问的东西，不追新、不堆砌。

欢迎 issue 交流，或直接在 skill 页面给我反馈。
