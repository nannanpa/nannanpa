# 你好，我是 MA Bin（nannanpa）

深耕高校公文与规划场景，把实战沉淀做成零依赖、规则可读可改的 agent skills。

## 主力项目：[agent-skills](https://github.com/nannanpa/agent-skills)

一个面向高校公文与办公场景的实战技能库，遵循开放的 [Agent Skills 规范](https://agentskills.io)，可在 Claude Code、WorkBuddy 等兼容 agent 中直接使用。技能覆盖公文写作、文档处理、知识梳理与工程自动化几类。

## 信念

- **零依赖优先**：能标准库解决就不引第三方，拷过来就能跑。
- **规则可读可改**：把判据和方法论写进 SKILL.md，而不是封装成黑箱——你要能看懂、能改、能拿去适配自己的场景。
- **实战沉淀**：只收录反复用过、经得起拷问的东西，不追新、不堆砌。

欢迎到 [agent-skills](https://github.com/nannanpa/agent-skills/issues) 提 issue 交流。
